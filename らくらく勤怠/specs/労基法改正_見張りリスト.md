# 労働基準法 改正 見張りリスト（施行時に着手）

最終更新: 2026-08-19 ／ 記録者: カイ（実装）。法的判断は必ず有資格の社会保険労務士に確認する。

## 現状（2026-08 時点）
- 40年ぶりとされる労基法の大改正が議論中だが、**2026年通常国会への改正案提出は「見送り」**。まだ施行されていない。
- よって**現時点で修正が必要な箇所はない**。本ファイルは「施行が決まったら着手する」ための備忘。
- 直近で**施行済み**の大改正（2023年4月・中小企業への月60時間超割増50%）は**実装済み**（`overtime60Rate: 1.5`）。

## 我々のシステムの現行実装値（参照）
- 法定労働時間：日8h(480分) / 週40h(2400分)　… `src/lib/payroll/aggregate.ts`
- 割増：時間外25% / 月60h超50% / 深夜25% / 法定休日35%　… `src/lib/payroll/settings.ts`（会社ごとに設定変更可）
- みなし休憩：6h超45分 / 8h超60分（労基法34条）
- 端数丸め：切り捨て一方向は禁止（切上/四捨五入のみ）
- 有給：付与/取得の記録＋残高（失効=付与+2年）。**有給取得時の賃金計算は未対応（対象外）**

## 施行されたら着手する候補（優先度は施行内容で再判定）

| 論点 | 我々への影響 | 対応方針 |
|---|---|---|
| **週44時間特例の廃止** | 影響なし（最初から週40hのみ実装） | 対応不要 |
| **法定休日の特定義務化** | 会社設定で法定休日の曜日指定は既にあり | 就業規則の明示運用に合わせ、設定UIの文言を補強する程度 |
| **連続勤務上限（14連勤禁止）** | 未実装 | シフト/打刻から連続勤務日数を検知しアラート（コンプラ画面に追加） |
| **勤務間インターバル義務化** | 未実装 | 退勤→翌出勤の間隔を検知しアラート |
| **有休の通常賃金方式** | 有休賃金は未計算（対象外） | 給与集計に有休賃金の払い方（通常/平均/標準報酬）を選べる設定を追加 |
| **副業・兼業の割増通算見直し** | マルチテナントで会社をまたぐ通算はしない | 原則スコープ外。要件化されたら別途検討 |

## 運用ルール
- 施行日・具体的な要件が確定したら、**労務顧問「ミオ」に一次レビュー**させ、実装後に**有資格社労士の確認**を経て本番反映する（rules.md の承認フロー準拠）。
- 割増率・しきい値はコード改修不要で会社設定から変更できる（`company_payroll_settings`）。レート改定は設定変更で対応。
