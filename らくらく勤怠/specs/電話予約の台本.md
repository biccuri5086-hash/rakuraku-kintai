# 専門家相談 電話予約の台本

作成日：2026年9月22日／対象：運営者本人が電話する際にそのまま読める台本。

> 一般的な「法律相談センター」は個人の債務整理・離婚・相続相談が中心のため、経営者から見ると
> 場違いに感じることがある。そこで、事業者向けに運営されている窓口を優先候補にしている。

## 優先順位

1. **あいち中小企業法律支援センター**（愛知県弁護士会／中小企業・個人事業主専用の窓口）
2. **名古屋商工会議所「専門相談」**（弁護士・社労士・税理士・弁理士が揃う。非会員も利用可）
3. （社労士を急ぐ場合）愛知県「専門労働相談」
4. （バックアップ）愛知県社会保険労務士会

「あいち労働総合支援フロア」は雇う側・雇われる側の労使トラブル相談が主目的のため、
利用規約まわりの相談先としては外している（社労士側の一般的な労働相談としてなら使える）。

- 電話：052-265-6693
- 受付：平日10:00〜12:00／13:00〜15:00

```

（日時を聞かれたら、都合の良い候補を2〜3個伝える）

ありがとうございます。当日は資料（利用規約の該当箇所）を手元に用意してお電話します。
よろしくお願いいたします。
```

- オンライン予約：https://reserva.be/nagoyacci
- 特徴：非会員も利用可。同じ窓口で弁護士・社労士どちらも予約できる可能性

```
もしもし、専門相談の予約についてお伺いしたく、お電話しました、小原と申します。
個人で勤怠管理のソフトウェアの会社を1人でやっておりまして、会員ではないのですが、
専門相談は非会員でも利用できると伺いました。
相談したいのは2点あり、1つは利用規約の内容について弁護士の先生に、もう1つは
給与計算・労働者派遣法まわりについて社労士の先生に伺いたいです。
同じ日に両方予約することは可能でしょうか。

（日程調整。オンライン予約でも良いか聞かれたら、それでも構わない旨を伝える）

ありがとうございます。当日はご相談したい内容をまとめた資料を持参します。
よろしくお願いいたします。
```

## 電話で聞かれたら困りそうなこと・想定問答

- 「法人ですか、個人事業主ですか」→ 個人事業主（またはその時点の実態を答える）
- 「相談内容を簡単に教えてください」→ 「勤怠管理のSaaSを運営していて、利用規約の
  賠償責任条項が有効か確認したい」「給与計算ロジックが労基法に沿っているか確認したい」
- 「顧問契約が必要になりますが」→ まずはスポット・単発の相談を希望している旨を伝える
- 「資料はありますか」→ ある、と答えてよい（`相談資料_弁護士社労士.pptx`・
  `弁護士相談資料.md`・`社労士相談資料.md`を参照しながら話す）
