## セキュリティ設定（推奨）

### パスワードの変更

初回ログイン後、画面右上の鍵アイコンから、ご自身だけが知るパスワードに変更してください。

**設定できる条件**

| 条件 |
|---|
| 12文字以上 |
| 英字（a〜z / A〜Z）を1文字以上 |
| 数字（0〜9）を1文字以上 |
| 記号（! # $ % & @ ? + = など）を1文字以上 |

入力中に、条件を満たしているかが画面に表示されます。あわせて、サービス名や
メールアドレスをそのまま含むもの、`12345` のような連続した並びは登録できません。

- **他のサービスと使い回さないでください**
- ブラウザのパスワード保存やパスワード管理アプリに保管してください
- 全角文字は使えません（ログイン時の打ち間違いを防ぐためです）

すでにお使いのパスワードが条件を満たしていない場合、ログイン時に変更のご案内が
表示されます。その場で変更していただけますが、「あとで変更する」でそのまま
管理画面に進むこともできます。

パスワードを忘れた場合は、サービス提供元にご連絡ください。再発行します。

### ログインを保持する（毎回の入力を省く）

ログイン画面の「**このブラウザで7日間ログインしたままにする**」にチェックを入れて
ログインすると、7日間はメールアドレス・パスワード・6桁コードの入力が不要になります。
次に管理画面を開いたとき、そのまま表示されます。

- パスワードは保存されません。ログインした状態が7日間続く仕組みです
- **共用のパソコンではチェックを外してください**
- 7日を過ぎたら、もう一度だけ入力していただきます
- パスワードを変更すると、それまでに記憶したブラウザはすべて解除されます

### 2要素認証（2FA）

管理画面ではスタッフの給与額や連絡先を扱うため、2要素認証の設定をおすすめします。
設定すると、パスワードが漏れても、お手元のスマホが無ければログインできなくなります。

**設定手順**

1. スマホに認証アプリを入れる（Google Authenticator / Microsoft Authenticator / 1Password など。無料）
2. 管理画面の右上にある**盾のアイコン**を押す
3. 表示されたQRコードを認証アプリで読み取る
4. アプリに出た6桁の数字を入力して「確認」を押す
5. 「有効にする」を押す

次回のログインから、パスワードの後に6桁コードの入力を求められます。

> **スマホを機種変更するときは、変更前に同じ画面で登録し直してください。**
> スマホを失くしてログインできなくなった場合は、サービス提供元にご連絡ください。解除できます。

解除するときは同じ画面から行えます（確認のため現在のパスワードの入力が必要です）。

## ダッシュボードの見方

### サマリーカード（上部3つ）

| カード | 意味 |
|---|---|
| 登録スタッフ数 | 打刻したスタッフの総数 |
| 出勤済み | 当日出勤済みのスタッフ数 |
| 要フォロー ⚠️ | コンディションスコアが低い（2以下）スタッフ数 |

### スタッフ一覧テーブル

| 列 | 意味 |
|---|---|
| 名前 | LINEの表示名 |
| 出勤 | 出勤打刻時刻 |
| 退勤 | 退勤打刻時刻（未退勤は --:--） |
| 勤務時間 | 出退勤の差分 |
| コンディション | 当日の報告スコア（絵文字+ラベル） |

### ⚠️ 要フォローの見方

コンディションが「少し疲れ」または「しんどい」のスタッフは**行が赤背景**で表示されます。
名前の前に「!」マークが付きます。

→ 早めに声をかけることで離職防止に繋がります。
