# ラクラク勤怠 サービス全体像
**〜 仕組みと機能のご紹介 〜**

---

## 1. このサービスは何か

派遣会社向けの勤怠管理SaaS。3者が関わる。

| 立場 | やること | 入口 |
|---|---|---|
| 派遣スタッフ | LINEで打刻・コンディション報告 | LINE(LIFF) |
| 派遣会社の管理者 | 出退勤確認・シフト/契約/給与/コンプラ管理 | Web管理画面 `/admin` |
| 運営（自社） | 契約会社（テナント）の管理 | Web管理画面 `/superadmin` |

一つのシステムを、契約している派遣会社ごとに分けて（テナントごとに分離して）提供している。

---

## 2. 全体の仕組み（データの流れ）

```
📱 スタッフのスマホ（LINE）
   → 🌐 Vercel（アプリ本体・サーバー処理）
   → 🔑 LINE（本人確認）
   → 🗄️ Supabase（データベース・全データの保管先）
   → 💻 管理者のパソコン（管理画面で確認）
```

- 通信はすべてHTTPSで暗号化
- スタッフのスマホ本体にはデータを残さない（サーバー側に集約）
- 派遣会社ごとにデータが分離される設計（他社のデータは見えない）

---

## 3. データモデルの考え方

単発の仕事も、長期の仕事も、同じ仕組みで扱う。

```
companies（派遣元＝契約している派遣会社）
   └ clients（派遣先企業）
        └ assignments（契約・アサイン：単発 or 中長期）
             └ shifts（シフト：予定・確定・完了・欠勤）
                  └ attendance（実際の打刻データ）
```

これにより、「今日1日だけの仕事」も「数ヶ月契約の仕事」も、同じデータ構造の上で
シフト管理・勤怠集計・給与計算までつながる。

---

## 4. スタッフ機能（LINEで完結）

| 機能 | 内容 |
|---|---|
| 登録 | 初回のみ電話番号を入力（アプリDL不要） |
| 打刻 | 「出勤する」「退勤する」を1タップ |
| コンディション報告 | 5段階の絵文字で「今日の調子」を毎日記録（5秒） |
| GPS記録 | 打刻時に位置情報を自動取得（不正打刻の確認に活用） |

スマホ操作が苦手なスタッフでも、当日から迷わず使える。

---

## 5. 管理者機能①：日々の現場管理

| 機能 | 内容 |
|---|---|
| ダッシュボード | 全スタッフの出退勤状況とコンディションを一覧表示 |
| 要フォローアラート | コンディションが悪いスタッフを自動で可視化 |
| シフト管理 | シフトの予定・確定・完了・欠勤を管理 |
| 派遣先・契約管理 | 派遣先企業（clients）、契約/アサイン（assignments）の登録・管理 |

---

## 6. 管理者機能②：バックオフィス業務

| 機能 | 内容 |
|---|---|
| 給与集計 | 勤怠データから給与を自動集計（設定画面あり） |
| 有給管理 | スタッフの有給取得状況を管理 |
| 派遣法コンプライアンス | 抵触日を基準に「余裕あり／要注意／超過」を自動判定 |
| 請求（billing） | 派遣先向けの請求管理 |
| 監査ログ | ログイン・操作履歴を記録（誰が・いつ・何をしたか） |
| 派遣先向けレポート | client-report として出力 |

---

## 7. 運営（自社）機能

- 契約している派遣会社（テナント）の追加・管理を `/superadmin` から実施
- 管理者・運営ともに2段階認証（2FA）に対応
- パスワードは12文字以上・英字/数字/記号必須のポリシーで統一管理

---

## 8. 技術構成（参考）

- フロントエンド：Next.js（App Router）+ TypeScript
- データベース：Supabase（PostgreSQL）
- 認証基盤：LINE LIFF（スタッフ側）／メール・パスワード・2FA（管理者・運営側）
- デプロイ：Vercel

---

## まとめ

「LINEで完結する打刻・コンディション報告」を入口に、
シフト・契約・給与・派遣法コンプライアンスまでを1つのデータ基盤でつなげているのが
ラクラク勤怠の全体像。
